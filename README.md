# 没人相信我打美职篮

> 模拟我的篮球生涯。从选秀夜开始，写下你自己的结局。

一款单机文字篮球生涯模拟游戏：既可以模拟 12 位真实球星的生涯，也可以自建球员，从选秀夜开始闯进联盟。

## 本地运行

Windows 下双击：

```text
启动本地服务器.cmd
```

默认地址：

```text
http://127.0.0.1:8765/
```

也可以用任意静态服务器指向项目根目录，入口是 `index.html`。

## 当前内容

- 模拟明星：12 位球员、原版专属主线/事件、统一后的天赋页与成长面板。
- 自建球员：出身 → 打法 → 难度 → 确认，四步捏人。
- 比赛：常规赛 82 场、全明星、交易截止、附加赛/季后赛。
- 成长：比赛表现驱动 XP + 专精点提高潜力 + 年龄曲线。
- 结局：9 类「名字的回声」结局 + 自白兑现 + 下半场选择。
- 平台：Lamps 多文件 ZIP 结构，已接入云存档、排行榜、激励视频。

## 目录

```text
index.html            入口壳
assets/
  js/                 游戏逻辑（001–178）
  css/                主题与页面样式
  *.jpg / *.png       立绘、场景、荣誉图标
  logos/              30 支球队 Logo
tools/                split / build / serve 脚本
游戏策划文档.md        系统、数值、平台、广告
剧情设定-出身与年代.md  出身、年代、自白、结局文案
M1-开发日志.md         迭代记录
```

## 注意

- `preview.html`、上传 ZIP、`_backup/`、`tools/cloudflared.exe` 不入库，属于本地构建/调试产物。
- 立绘、球队 Logo、真实球员相关内容仅用于开发原型；公开上线前需确认肖像、商标与平台审核要求。
- 修改素材后运行 `tools/build-preview.ps1` 和 `tools/build-zip.ps1` 重新生成预览与上传包。
